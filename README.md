# Bike Sync updates

This public repository distributes verified updates for the Bike Sync macOS menu-bar app.

- `latest.json` is the update manifest read by the app.
- `UPDATE LOG.md` records every published version and its user-visible changes.
- Installer files are attached to GitHub Releases.

This repository contains no athlete profiles, credentials, routes, Intervals.icu data, health data, or private coaching information.
