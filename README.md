# Bike Sync for macOS

Bike Sync is a customizable menu-bar companion for Intervals.icu. It supports Intel and Apple-silicon Macs and contains no athlete profile, credentials, routes, health data, or private coaching information.

Optional integrations include Intervals.icu, Strava, VeloViewer's user-generated segment CSV, supported wellness providers through Intervals.icu, and a private ChatGPT coaching bridge. Clean installations keep personal automations off until the user configures them.

## Download

[Download the latest Bike Sync installer](https://github.com/bsg837/bike-sync-updates/releases/latest)

Open the newest release, download the file whose name ends in `Installer.zip`, and follow the included `READ ME.html`. The same page contains release notes and a SHA-256 checksum.

## Updates

After the first installation, Bike Sync can download signed updates automatically. Each update is checked against both its published SHA-256 checksum and Bike Sync publisher signature before installation.

## Support development

Bike Sync is available without payment. A voluntary support link will appear here after the maintainer connects a donation provider; donations will not unlock features or affect updates.

This repository distributes only public application updates. It contains no athlete profiles, credentials, routes, Intervals.icu data, health data, or private coaching information.
